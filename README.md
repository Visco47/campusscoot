# Campus Scooter Rental App

## Overview

A modern web application for tracking and renting campus scooters with real-time availability and battery status.

## Features

- View available and rented scooters
- Dark/Light mode toggle
- Responsive design
- Scooter details card with image, battery percentage

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Theme

Clean Light theme with automatic dark/light mode switching
